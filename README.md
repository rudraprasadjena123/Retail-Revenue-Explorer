# GiftRetail Insights 📊

An Excel-based sales analytics project focused on understanding retail sales performance, product demand, customer locations, gifting occasions, and delivery efficiency.

## 📌 Project Overview

This project analyzes sales data from a gifting retail business to identify business trends and generate useful insights. Using Microsoft Excel, the project explores transaction data through data preparation, calculations, PivotTables, charts, and dashboard visualization.

The objective is to transform raw sales data into meaningful information that can support better business decisions.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Understand monthly sales trends.
- Identify top-performing products.
- Analyze customer order patterns across cities.
- Compare sales across different gifting occasions.
- Examine order quantities and delivery duration.
- Present key metrics through an interactive Excel dashboard.

## 🔍 Analytical Approach

1. Inspect the order, product, and customer datasets.
2. Review data types, missing values, date fields, and duplicate identifiers.
3. Calculate estimated sales value using quantity multiplied by listed price, subject to validation of the price definition.
4. Summarize performance by month, product, city, and occasion.
5. Examine delivery-duration patterns and their relationship with order quantity.
6. Create dashboard KPIs, charts, and comparisons.
7. Validate the results against the underlying data before drawing conclusions.

## 💡 Business Value

This analysis can help a gifting retailer explore:

- Seasonal demand and sales fluctuations
- Products that contribute strongly to sales
- Geographic differences in order volume
- Customer preferences across gifting occasions
- Opportunities to review delivery operations

These insights can support inventory planning, marketing decisions, and further business analysis.

## ⚠️ Limitations and Data Privacy

- The analysis uses a supplied sample dataset, not live company reporting.
- Estimated sales value depends on the correct interpretation of quantity and listed price.
- Average value per row may differ from average order value if an order contains multiple rows.
- A relationship between order quantity and delivery duration does not establish causation.
- Only sanitized datasets should be published. Do not upload customer names, phone numbers, email addresses, or full addresses.
